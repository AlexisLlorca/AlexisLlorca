# ¡Hola! Soy Alexis Emmanuel Llorca 👋

## 🚀 Sobre Mí
Soy un estudiante apasionado de **Desarrollo de Aplicaciones Multiplataforma (DAM)**, actualmente preparándome para comenzar mi segundo año y el período de **Formación en Centros de Trabajo (FCT)**. 

Me especializo en el desarrollo de software robusto utilizando el ecosistema de **Java**, con un fuerte enfoque en la arquitectura limpia, la persistencia de datos y el diseño orientado a objetos. Como usuario de **Linux (CachyOS / Arch Linux)** y **Windows**, disfruto de la automatización, la optimización de entornos de desarrollo y el trabajo eficiente con la terminal.

* 🎯 **Mi objetivo actual**: Consolidar mis habilidades técnicas y aportar valor real como desarrollador junior durante mis prácticas de FCT.
* 🛠️ **En qué estoy trabajando**: El ecosistema **ProjectCraft**, una serie de proyectos modulares que demuestran el control de lógica de negocio, bases de datos (JDBC/JPA) e interfaces gráficas (JavaFX).
* 🧠 **Filosofía de desarrollo**: *"Escribe código para humanos, no solo para máquinas. El código limpio y bien probado ahorra semanas de depuración en producción".*

## 📂 Portafolio Destacado

### ☕ [ProjectCraft-Console](https://github.com/AlexisLlorca/ProjectCraft-Console)
Un sistema de gestión de Recursos Humanos enfocado en la **Programación Orientada a Objetos Avanzada** y la robustez del código.
*   **Conceptos clave**: Herencia, Polimorfismo, interfaces como contratos, tratamiento avanzado de excepciones de negocio y persistencia en ficheros locales mediante I/O seguro.
*   **Tecnologías**: Java SE, JUnit 5, Git semántico.

### 🗄️ [ProjectCraft-JPA-Core](https://github.com/AlexisLlorca/ProjectCraft-JPA-Core) *(Próximamente)*
La capa de persistencia y acceso a datos de la aplicación corporativa, mapeando un modelo de negocio complejo a bases de datos relacionales.
*   **Conceptos clave**: Patrón de diseño DAO, prevención de inyección SQL mediante `PreparedStatement`, control de transacciones manuales, mapeo ORM mediante JPA/Hibernate y bases de datos orientadas a objetos.
*   **Tecnologías**: Java, JPA, Hibernate, MySQL, Maven.

### 🖥️ [ProjectCraft-Dashboard](https://github.com/AlexisLlorca/ProjectCraft-Dashboard) *(Próximamente)*
Una aplicación de escritorio interactiva con un panel visual para la gestión de proyectos y la generación de informes financieros.
*   **Conceptos clave**: Desarrollo de interfaces gráficas basadas en el modelo de escena por nodos, control de eventos interactivos mediante expresiones lambda y desacoplamiento arquitectónico.
*   **Tecnologías**: JavaFX, FXML, CSS, JPA.
